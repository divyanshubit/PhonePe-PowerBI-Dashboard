
# PhonePe Transaction Analysis Dashboard - Power BI Project

## Project Overview

This is an End-to-End Data Analysis Project built using Power BI. The dashboard is designed to analyze PhonePe transaction data and provide actionable insights into transaction performance, payment success rates, failed payments, and service-wise transaction trends.

The project simulates a real-world business scenario where decision-makers need to monitor transaction activities across multiple services and identify key performance indicators.

## Services Covered

* Insurance Payments
* Loans
* Money Transfers
* Recharge & Bills

## Dashboard Features

### Homepage Dashboard

* Total Transaction Amount
* Total Transactions
* Successful Transactions
* Failed Transactions
* Date Range Slicer
* Service-wise Transaction Analysis

### Service Analysis

Each service contains dedicated visualizations:

* Amount vs Month Analysis
* Service vs Amount Comparison
* Payment Status Distribution
* Monthly Transaction Trends

### Failed Payment Analysis

The dashboard provides detailed insights into failed transactions and highlights reasons such as:

* Server Error
* Insufficient Balance
* Wrong Payment Details
* Technical Issues
