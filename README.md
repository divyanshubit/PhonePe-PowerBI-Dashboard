
# PhonePe Transaction Analysis Dashboard

## Project Overview

This is an End-to-End Data Analysis Project built using Power BI. The dashboard analyzes PhonePe transaction data and provides insights into transaction performance, payment success rates, failed payments, and service-wise transaction trends.

The project simulates a real-world business scenario where businesses need to monitor transactions, identify payment failures, and track service performance using interactive dashboards.

---

## Services Covered

* Insurance Payments
* Loans
* Money Transfers
* Recharge & Bills

---

## Dashboard Features

### Homepage Dashboard

* Total Transaction Amount
* Total Transactions
* Successful Transactions
* Failed Transactions
* Interactive Date Range Filter

### Service Analysis

Each service includes:

* Amount vs Month Analysis
* Service vs Amount Comparison
* Payment Status Distribution
* Monthly Transaction Trends

### Failed Payment Analysis

Detailed analysis of failed transactions including:

* Server Errors
* Insufficient Balance
* Wrong Payment Details
* Technical Issues
